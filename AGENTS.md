# Project Workspace Directives & Autonomous Skill Activation

## Automatic Skill Rules
This repository is configured with specialized development skills in `.agents/skills/`. The AI assistant must automatically adhere to the following workflows:

1. **UI/UX & Page Layout**: Always apply `modern-web-craft` for modern minimal aesthetics, clean typography (K2D), curated school colors, and human-centered visual hierarchy.
2. **Debugging & Glitches**: Always apply `systematic-debugging` (4-phase root cause analysis) rather than guesswork.
3. **Ambiguity & New Features**: Always apply `brainstorming` to clarify intent and weigh design trade-offs before implementation.
4. **Complex Tasks & Migrations**: Always apply `writing-plans` to create step-by-step verifiable roadmaps.
5. **Pre-flight Quality & Security**: Always apply `requesting-code-review` to check XSS/SQL safety, run PHP syntax linter (`php -l`), and verify HTTP 200 responses.
6. **Critical Logic & Computations**: Always apply `test-driven-development`.
